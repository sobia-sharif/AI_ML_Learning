## 📖 Overview

This repository contains my Python practice exercises as part of the **NAVTTC Artificial Intelligence, Machine Learning & Deep Learning** program. 

It covers foundational concepts of programming including loops, functions, variable scopes, lambda expressions, built-in functional tools (`map` & `filter`), nested logic, and basic file handling using **Google Colab**.

---

## 🎯 Concepts Covered

- 🔁 **Control Flow & Loops:** `while` loops, user-defined inputs, multiplication tables, and counter increment/decrements.
- 🧩 **Functions & Arguments:** Function creation, parameter passing, return statements, and understanding standard output behavior.
- 📐 **Practical Utility Functions:** Temperature unit converters (Fahrenheit to Celsius) and score predictors.
- 🌐 **Variable Scope:** Local vs. Global variable demonstration.
- ⚡ **Lambda Expressions:** Anonymous functions, inline conditionals (even/odd), and fast mathematical evaluations.
- 🛠️ **Higher-Order Functions:** Using `map()` for transformations and `filter()` for conditional filtering on lists.
- 📦 **Nested Functions:** Outer and inner scope function executions.
- 📁 **File Handling:** Creating, writing, and reading plain text files.

---

## 💻 Included Python Examples

Here is a summary of the key scripts practiced in the notebook:

1. **Loops & Inputs:**
   - Counting numbers (1 to 10, 5 to 15, and reverse order from 20 to 1).
   - Dynamic user-input range printers and table generators.
2. **Custom Functions:**
   - Standard greetings and arithmetic addition functions.
   - Formula-based Fahrenheit to Celsius temperature conversion.
   - Logic predictor (`pass`/`fail` evaluator).
3. **Lambda Functions:**
   - Check even or odd numbers inline.
   - Dynamic inline addition and squaring functions.
4. **Map & Filter Utilities:**
   - Incrementation, multiplication, and uppercase text transformation using `map()`.
   - List filtering by numerical conditions and length checks using `filter()`.
5. **File Handling:**
   - File creation and reading through standard Python file methods and shell integration.
